# Research Horse Breed

You are helping maintain the Horse Breeds Notion database for a shareable educational site.

## Hard rules
- Only use official breed association / registry websites and clearly attributed primary sources.
- Never use or cite Wikipedia or Reddit.
- Always record the source URL(s) for every factual claim.
- Leave Status as Draft (or Needs review). Never mark Ready.
- Prefer concise, accurate content over long essays.

## Steps
1. Confirm the breed name with the user if it is ambiguous.
2. Research from official sources (AQHA, Jockey Club, Arabian Horse Association, Appaloosa Horse Club, etc.).
3. Collect:
   - Height range
   - Typical colors
   - Primary uses
   - Temperament
   - Short description (2–4 sentences)
   - Key characteristics
   - Brief history notes
   - Official association URL
4. Note any candidate images (with source/attribution) but do not download them yet.
5. Output the result as clean structured text matching the Notion properties, ready for the user to paste or for a later Notion-write step.
6. List the sources used at the bottom.

## Output format
Present the draft clearly labeled by field so it can be copied into Notion.
