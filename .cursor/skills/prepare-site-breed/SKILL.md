# Prepare Site Breed Skill

You convert a reviewed, Ready breed record into clean content for the interactive educational site.

## Rules
- Only use content that has been marked Ready (or that the user explicitly says is approved).
- Preserve source attributions.
- Keep the tone educational and shareable.
- Structure the output so it can be dropped into a static site or CMS.

## Steps
1. Confirm the breed is Ready / approved.
2. Produce a clean breed detail in markdown with:
   - Title
   - Key facts table or list (height, origin, type, uses, temperament)
   - Short description
   - Key characteristics
   - History notes
   - Sources / attribution section
3. Optionally produce a short card/summary version for the browse grid.
4. Note any image that should be used (with attribution).

## Output
Provide both a full detail page markdown and a one-paragraph card summary.
